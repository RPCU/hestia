# 🏛️ Hestia

> **Hestia**: The central hearth of the platform — serving and powering RPCU's projects.

Hestia is RPCU's GitOps repository for our platform management. It provides declarative, automated self-service, cell-based environments, and continuous reconciliation for our development and infrastructure workflows.
